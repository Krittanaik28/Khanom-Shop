# ขนมปังปุญ — เว็บขายขนม

เว็บหน้าร้าน + หลังร้าน เป็นไฟล์ static ล้วน วางบน **GitHub Pages** ได้เลย
ออเดอร์และข้อมูลลูกค้าเก็บใน **Google Sheet ของคุณ** ผ่าน Google Apps Script
ไม่ต้องเช่าเซิร์ฟเวอร์ ไม่ต้องเปิดคอมทิ้งไว้

| สินค้า | ราคา | หน่วย | รูป |
|---|---|---|---|
| ขนมปังเนยหนึบ | 120 ฿ | ถุง | น1, น2 |
| บราวนี่ | 150 ฿ | กล่อง | บ1, บ2 |
| ป็อปคอร์นคาราเมล | 200 ฿ | กระปุก | ป1, ป2 |

## ภาพรวมระบบ

```
ลูกค้าเปิดเว็บ (GitHub Pages)  ──POST──►  Apps Script  ──เขียน──►  Google Sheet ของคุณ
คุณเปิด admin.html + ล็อกอิน   ──POST──►  Apps Script  ──อ่าน──►   Google Sheet ของคุณ
```

- หน้าเว็บทั้งหมดเป็น HTML/CSS/JS ธรรมดา ไม่มีขั้นตอน build ไม่ต้องลง npm
- Apps Script ทำหน้าที่เป็นตัวกลาง ตรวจข้อมูล คิดเงิน และคุมสิทธิ์การอ่าน
- ลูกค้าสั่งซื้อได้โดยไม่ต้องล็อกอิน แต่การ **อ่าน** ออเดอร์และลูกค้าต้องล็อกอินเสมอ

## เริ่มใช้งาน 3 ขั้น

### 1. ต่อกับ Google Sheet

ทำตาม [`apps-script/SETUP.md`](apps-script/SETUP.md) ใช้เวลาราว 10 นาที ทำครั้งเดียว
สรุปสั้น: สร้าง Sheet → Extensions → Apps Script → วางโค้ดจาก `apps-script/Code.gs`
→ Deploy เป็น Web app (Execute as: Me, Who has access: Anyone) → ก็อป URL

### 2. ใส่ลิงก์ในเว็บ

แก้ `js/config.js`

```js
window.KHANOM_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/AKfycb.../exec'
};
```

### 3. ตั้งบัญชีแอดมิน

เปิด `admin.html` จะเจอหน้าสร้างบัญชี ตั้งชื่อผู้ใช้และรหัสผ่านของคุณ
**ทำทันทีหลัง deploy** เพราะระหว่างที่ยังไม่มีบัญชี ใครที่รู้ลิงก์ก็ชิงตั้งก่อนได้

จากนั้นเปิด `index.html` ลองสั่งซื้อหนึ่งครั้ง แล้วดูว่าแถวใหม่ขึ้นใน Sheet

> ทดสอบในเครื่องได้เลยด้วยการดับเบิลคลิก `index.html` ไม่ต้องรันเซิร์ฟเวอร์อะไร

## ใส่รูปสินค้า

วางรูป 6 ใบในโฟลเดอร์ `images/` ตามชื่อไฟล์ในตาราง — ดูที่ [`images/README.md`](images/README.md)
ถ้ายังไม่ใส่ เว็บจะแสดงกรอบ placeholder ให้ ใช้งานได้ปกติ

## เอาขึ้น GitHub Pages

```powershell
cd c:\Kiro\khanom-shop
git init
git add .
git commit -m "เว็บขายขนม เก็บข้อมูลผ่าน Google Sheet"
git branch -M main
git remote add origin https://github.com/<username>/khanom-shop.git
git push -u origin main
```

แล้วไปที่ **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`**
รอ 1-2 นาที เว็บจะขึ้นที่ `https://<username>.github.io/khanom-shop/`

ไม่ต้องแก้อะไรเพิ่ม ลิงก์ Apps Script ใน `js/config.js` ทำงานข้ามโดเมนได้อยู่แล้ว

## ข้อมูลเก็บที่ไหน

ทุกอย่างอยู่ใน Google Sheet ของบัญชี Google คุณ

| ชีต | เก็บอะไร |
|---|---|
| `Orders` | ออเดอร์ทุกรายการ พร้อมสถานะและยอดเงิน |
| `Customers` | ลูกค้า จับคู่ด้วยเบอร์โทร รวมยอดซื้อสะสมและจำนวนครั้ง |

- ชื่อผู้ใช้และ hash รหัสผ่านแอดมินอยู่ใน **Script Properties** ของ Apps Script
  ไม่ได้อยู่ใน Sheet และไม่ได้อยู่ในโค้ดที่ push ขึ้น GitHub
- เบราว์เซอร์ลูกค้าเก็บแค่ตะกร้าของตัวเอง ไม่มีข้อมูลลูกค้ารายอื่น
- ถ้าติดต่อ Google ไม่ได้ หน้าร้านจะแจ้งลูกค้าให้โทรหรือทักแชต
  พร้อมปุ่มคัดลอกรายละเอียดออเดอร์ ไม่บันทึกทิ้งไว้ในเครื่องลูกค้าแบบเงียบ ๆ

### ข้อมูลลูกค้าที่เก็บ

ชื่อ, เบอร์โทร, อีเมล (ถ้ากรอก), ที่อยู่จัดส่ง, การยินยอม, จำนวนออเดอร์,
ยอดซื้อสะสม, วันที่ซื้อครั้งแรก/ล่าสุด — สั่งซ้ำด้วยเบอร์เดิมจะอัปเดตยอดสะสมให้เอง

หน้าเช็คเอาต์บังคับติ๊กยินยอมก่อนสั่ง (PDPA) และแยก consent การตลาด
ออกจากการใช้ข้อมูลเพื่อจัดส่ง ฝั่ง Apps Script ปฏิเสธออเดอร์ที่ไม่มีการยินยอม

## ระบบล็อกอินแอดมิน

| เรื่อง | วิธีที่ใช้ |
|---|---|
| รหัสผ่าน | PBKDF2-HMAC-SHA256 5,000 รอบ + salt สุ่ม 16 ไบต์ |
| เทียบรหัส | เปรียบเทียบแบบใช้เวลาคงที่ กันการวัดเวลาเดารหัส |
| เซสชัน | โทเคนสุ่ม 256 บิต หมดอายุ 7 วัน เก็บใน `sessionStorage` |
| ในฝั่ง Google | เก็บแค่ SHA-256 ของโทเคน ไม่ได้เก็บโทเคนจริง |
| กันเดารหัส | ผิดเกิน 10 ครั้ง พักการล็อกอิน 15 นาที + หน่วงทุกครั้งที่ลอง |
| ข้อความ error | ไม่บอกว่าชื่อผู้ใช้ผิดหรือรหัสผิด |
| ตั้งบัญชีครั้งแรก | ทำได้ครั้งเดียว ตั้งซ้ำไม่ได้ |
| เปลี่ยนรหัส | ที่แท็บ "บัญชีของฉัน" เปลี่ยนแล้วเตะทุกอุปกรณ์ออก |

### ลืมรหัสผ่าน

เปิดหน้า Apps Script เลือกฟังก์ชัน `resetAdminAccount` แล้วกด **Run**
ออเดอร์และลูกค้าใน Sheet ไม่ถูกลบ แล้วกลับไปเปิด `admin.html` ตั้งบัญชีใหม่

## สิ่งที่ทำได้

**หน้าร้าน (`index.html`)**
- แกลเลอรีสินค้า 2 รูปต่อรายการ กดสลับได้
- เลือกจำนวน ใส่ตะกร้า ตะกร้าค้างอยู่แม้ปิดหน้าเว็บ
- ยอดที่ต้องจ่าย = ราคาสินค้ารวม ยังไม่คิดค่าส่งหรือค่าบริการใด ๆ
- ตรวจฟอร์มก่อนส่ง และ Apps Script ตรวจซ้ำอีกชั้นพร้อมคิดเงินใหม่เอง
- ได้เลขที่ออเดอร์ `ORD-YYYYMMDD-NNN` และคัดลอกสรุปออเดอร์ไปแชตได้

**หลังร้าน (`admin.html`)**
- หน้าล็อกอิน + ตั้งบัญชีครั้งแรก + เปลี่ยนรหัสผ่าน + ออกจากระบบ
- สรุปยอด: จำนวนออเดอร์ ยอดขาย จำนวนลูกค้า ออเดอร์ที่รอดำเนินการ
- ตารางออเดอร์ ค้นหา/กรองสถานะ เปลี่ยนสถานะ (ใหม่ → ชำระแล้ว → ส่งแล้ว → เสร็จสิ้น / ยกเลิก) และลบได้
- ดึงข้อมูลใหม่อัตโนมัติทุก 1 นาที
- ตารางลูกค้าเรียงตามยอดซื้อสะสม และยอดขายแยกตามสินค้า
- ส่งออก CSV (มี BOM อ่านภาษาไทยใน Excel ได้เลย)

## แก้ราคาสินค้า

ราคาอยู่ 2 ที่ และ **ฝั่ง Apps Script ถือเป็นราคาจริงที่ใช้คิดเงิน**

1. `apps-script/Code.gs` → ตัวแปร `PRODUCTS` (แก้แล้วต้อง Deploy ใหม่)
2. `js/products.js` → ใช้แสดงบนหน้าเว็บ

ถ้าสองที่ไม่ตรงกัน หน้าเว็บจะยึดราคาจาก Apps Script ให้อัตโนมัติและวาดสินค้าใหม่
พร้อมขึ้นคำเตือนใน Console ของเบราว์เซอร์ แต่ควรแก้ให้ตรงกันทั้งสองที่อยู่ดี

## ข้อจำกัดที่ควรรู้

1. **ลิงก์ Apps Script เป็นสาธารณะ** จำเป็นต้องเป็นแบบนั้นเพราะเบราว์เซอร์ลูกค้าต้องเรียกถึงได้
   ใครรู้ลิงก์ **ส่งออเดอร์ปลอมเข้ามาได้** (จำกัดไว้ 30 ออเดอร์ต่อ 10 นาที)
   แต่ **อ่านข้อมูลไม่ได้** ถ้าไม่ล็อกอิน ถ้าถูกกวนหนักให้ Deploy ใหม่เพื่อเปลี่ยน URL
2. **โทเคนล็อกอินอยู่ใน `sessionStorage` ไม่ใช่คุกกี้ HttpOnly** เพราะ Apps Script
   อยู่ต่างโดเมนจึงตั้งคุกกี้ให้เว็บเราไม่ได้ ถ้ามีช่องโหว่ XSS โทเคนถูกขโมยได้
3. **การจำกัดล็อกอินผิดนับรวมทั้งระบบ ไม่แยกตาม IP** เพราะ Apps Script ไม่บอก IP ผู้เรียก
   ผลข้างเคียงคือถ้ามีคนพยายามเดารหัสจนครบ คุณเองก็จะล็อกอินไม่ได้ 15 นาที
   วิธีแก้: ไปลบ property `loginFail` ในหน้า Apps Script
4. **PBKDF2 5,000 รอบ แข็งน้อยกว่า scrypt** เพราะ Apps Script ไม่มี scrypt/bcrypt ให้ใช้
   ควรตั้งรหัสผ่านยาวหน่อยเพื่อชดเชย
5. **มีบัญชีแอดมินได้บัญชีเดียว** ยังไม่มีระบบหลายผู้ใช้หรือแบ่งสิทธิ์ และไม่มี 2FA
6. **ไม่มีการชำระเงินอัตโนมัติ** ลูกค้าโอนพร้อมเพย์แล้วส่งสลิปมาทางแชต คุณกดเปลี่ยนสถานะเอง
7. **ไม่มีระบบสต็อก** สั่งเกินจำนวนที่ทำได้ ต้องมาเช็คเองในหลังร้าน
8. **โควตา Google บัญชีฟรี** ประมาณ 20,000 คำขอ/วัน เหลือเฟือสำหรับร้านขนม
