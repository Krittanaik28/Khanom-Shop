## เปลี่ยนรูปทีหลัง

วางไฟล์ใหม่ทับชื่อเดิมได้เลย ไม่ต้องแก้โค้ด
รองรับ `.jpg` `.jpeg` `.png` `.webp` — ถ้าเปลี่ยนนามสกุล ระบบจะลองหาให้เองตามลำดับ

ถ้าอยากใช้ชื่อไฟล์อื่น แก้ที่ `js/products.js` ในคีย์ `images`

## หมายเหตุเรื่องขนาดไฟล์

รวมทั้ง 6 ใบราว 1.6 MB ใช้บน GitHub Pages ได้สบาย
หน้าเว็บโหลดรูปแบบ lazy และครอบเป็นอัตราส่วน 4:3 ให้อัตโนมัติ (`object-fit: cover`)

`brownie-2.jpg` ใหญ่สุดที่ 584 KB ถ้าอยากให้โหลดไวขึ้นบนเน็ตมือถือ
ย่อความกว้างลงเหลือราว 1200px แล้วเซฟทับได้ คุณภาพที่เห็นบนเว็บไม่ต่างกัน
