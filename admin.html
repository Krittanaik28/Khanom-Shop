ต้องตั้งค่าก่อนใช้

ยังไม่ได้เชื่อมกับ Google Sheet

เว็บนี้เก็บข้อมูลไว้ใน Google Sheet ของคุณ ผ่าน Google Apps Script ต้องนำลิงก์ Web app มาใส่ในไฟล์ js/config.js ก่อน 

window.KHANOM_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/xxxx/exec'
};

ขั้นตอนละเอียดอยู่ในไฟล์ apps-script/SETUP.md ทำครั้งเดียวจบ

ติดต่อ Google ไม่ได้

ข้อมูลออเดอร์และลูกค้าอยู่ใน Google Sheet ของคุณ ตอนนี้เรียกถึงไม่ได้

  • ตรวจว่าเครื่องต่ออินเทอร์เน็ตอยู่
  • ตรวจว่า Apps Script ยัง deploy อยู่ และตั้ง Who has access เป็น Anyone
  • ถ้าเพิ่งแก้โค้ด Apps Script ต้องกด Deploy ใหม่ทุกครั้ง

ตั้งค่าครั้งแรก

สร้างบัญชีผู้ดูแลร้าน

ยังไม่มีบัญชีในระบบ ตั้งชื่อผู้ใช้และรหัสผ่านของคุณเพื่อใช้เข้าหลังร้าน รหัสผ่านถูกเก็บแบบเข้ารหัสทางเดียว (PBKDF2-SHA256) ไว้ใน Script Properties ของ Apps Script ไม่ได้อยู่ใน Google Sheet และไม่ได้อยู่ในโค้ดบน GitHub

ทำขั้นนี้ทันทีหลัง deploy เพราะระหว่างที่ยังไม่มีบัญชี ใครที่รู้ลิงก์เว็บสามารถชิงตั้งบัญชีก่อนได้

ยาว 3-40 ตัว ใช้ a-z 0-9 . _ - เท่านั้น

อย่างน้อย 8 ตัว มีทั้งตัวอักษรและตัวเลข

ถ้าลืมรหัส เปิดหน้า Apps Script แล้วสั่ง Run ฟังก์ชัน resetAdminAccount เพื่อตั้งใหม่ ออเดอร์ใน Sheet ไม่หาย

เปลี่ยนรหัสผ่าน

เปลี่ยนแล้วระบบจะออกจากระบบทุกอุปกรณ์ ต้องล็อกอินใหม่

อย่างน้อย 8 ตัว มีทั้งตัวอักษรและตัวเลข

ข้อมูลของคุณเก็บที่ไหน

  • ออเดอร์และลูกค้าอยู่ใน Google Sheet ของบัญชี Google คุณ ที่ชีต Orders และ Customers
  • เปิด Sheet ดูหรือแก้เองได้ตลอด และแชร์ให้ใครก็เท่าที่คุณกดแชร์
  • รหัสผ่านเก็บเป็น hash PBKDF2-SHA256 พร้อม salt สุ่ม ใน Script Properties ไม่ได้อยู่ใน Sheet
  • เบราว์เซอร์ของลูกค้าเก็บแค่ตะกร้าของตัวเอง ไม่มีข้อมูลลูกค้ารายอื่น
  • เซสชันล็อกอินหมดอายุใน 7 วัน และหลุดเมื่อปิดแท็บ

สำรองข้อมูล

ใน Google Sheet กด File → Make a copy เก็บไว้เป็นระยะ หรือกดส่งออก CSV จากแท็บออเดอร์และลูกค้าในหน้านี้
