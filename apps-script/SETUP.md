# ติดตั้ง Google Sheet + Apps Script (ทำครั้งเดียว ~10 นาที)

เว็บหน้าร้านเป็นไฟล์ static ล้วน วางบน GitHub Pages ได้เลย
ข้อมูลออเดอร์และลูกค้าไปเก็บใน Google Sheet ของคุณ ผ่าน Google Apps Script

```
ลูกค้าเปิดเว็บ (GitHub Pages)  ──POST──►  Apps Script  ──เขียน──►  Google Sheet ของคุณ
คุณเปิด admin.html + ล็อกอิน   ──POST──►  Apps Script  ──อ่าน──►   Google Sheet ของคุณ
```

---

## ขั้นที่ 1 สร้าง Google Sheet

1. เข้า https://sheets.new (ต้องล็อกอินบัญชี Google ที่จะใช้เก็บข้อมูล)
2. ตั้งชื่อไฟล์ เช่น `ขนมปังปุญ - ออเดอร์`
3. ไม่ต้องสร้างหัวตารางเอง สคริปต์จะสร้างชีต `Orders` และ `Customers` ให้อัตโนมัติ

## ขั้นที่ 2 ใส่โค้ด Apps Script

1. ใน Sheet นั้น ไปที่เมนู **Extensions → Apps Script**
2. จะเปิดแท็บใหม่ มีไฟล์ `Code.gs` และโค้ดตัวอย่าง `function myFunction() {}`
3. **ลบโค้ดเดิมทั้งหมด** แล้ววางเนื้อหาจากไฟล์ [`Code.gs`](Code.gs) ในโปรเจกต์นี้ลงไปทับ
4. กด **Save** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)

## ขั้นที่ 3 สร้างตารางให้พร้อม (ไม่บังคับ แต่ช่วยให้เห็นภาพ)

1. ในหน้า Apps Script เลือกฟังก์ชัน `initSheets` จากช่องรายการฟังก์ชันด้านบน
2. กด **Run**
3. ครั้งแรกจะขอสิทธิ์ กด **Review permissions → เลือกบัญชี → Advanced → Go to (ชื่อโปรเจกต์) (unsafe) → Allow**
   - คำว่า unsafe เป็นข้อความมาตรฐานของ Google สำหรับสคริปต์ที่เราเขียนเอง ไม่ได้ผ่านการรีวิวจาก Google
   - สิทธิ์ที่ขอคือแก้ Sheet ที่ผูกอยู่เท่านั้น
4. กลับไปดูที่ Sheet จะมีชีต `Orders` และ `Customers` พร้อมหัวตารางแล้ว

## ขั้นที่ 4 Deploy เป็น Web app

1. ในหน้า Apps Script กด **Deploy → New deployment**
2. กดไอคอนเฟือง ข้าง Select type แล้วเลือก **Web app**
3. ตั้งค่า

   | ช่อง | ค่าที่ต้องเลือก |
   |---|---|
   | Description | อะไรก็ได้ เช่น `khanom shop v1` |
   | Execute as | **Me (อีเมลคุณ)** |
   | Who has access | **Anyone** |

   > **Who has access ต้องเป็น Anyone** ไม่ใช่ "Anyone with Google account"
   > เพราะลูกค้าที่มาสั่งขนมไม่ได้ล็อกอิน Google
   > คำว่า Anyone หมายถึงใครก็เรียก URL นี้ได้ แต่จะ **อ่าน** ข้อมูลไม่ได้ถ้าไม่ล็อกอินในเว็บเรา

4. กด **Deploy** แล้วก็อป **Web app URL** เก็บไว้ หน้าตาแบบนี้

   ```
   https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxxx/exec
   ```

## ขั้นที่ 5 ใส่ลิงก์ในเว็บ

เปิดไฟล์ `js/config.js` ในโปรเจกต์ แล้วใส่ลิงก์ที่ได้

```js
window.KHANOM_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxxx/exec'
};
```

## ขั้นที่ 6 ตั้งบัญชีแอดมิน

1. เปิด `admin.html` (เปิดไฟล์ตรง ๆ ก็ได้ หรือเปิดผ่าน GitHub Pages)
2. จะเจอหน้า **สร้างบัญชีผู้ดูแลร้าน** ตั้งชื่อผู้ใช้และรหัสผ่าน
3. **ทำทันที** เพราะระหว่างที่ยังไม่มีบัญชี ใครที่รู้ลิงก์ก็ชิงตั้งบัญชีก่อนได้

เสร็จแล้ว ลองสั่งซื้อจากหน้าร้านหนึ่งครั้ง แล้วดูว่าแถวใหม่ขึ้นใน Sheet

## เวลาแก้โค้ด Apps Script ต้อง Deploy ใหม่

กด **Deploy → Manage deployments → ไอคอนดินสอ → Version: New version → Deploy**

ถ้าทำแบบนี้ URL เดิมจะใช้ได้ต่อ ไม่ต้องแก้ `js/config.js`
(ถ้ากด New deployment จะได้ URL ใหม่ ต้องไปแก้ config ด้วย)

## เครื่องมือที่รันได้จากหน้า Apps Script

เลือกชื่อฟังก์ชันจากรายการด้านบนแล้วกด Run

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `initSheets` | สร้างชีต Orders / Customers พร้อมหัวตาราง |
| `resetAdminAccount` | ลืมรหัสผ่าน — ล้างบัญชีแอดมินเพื่อตั้งใหม่ (ออเดอร์ไม่หาย) |
| `logoutAllDevices` | เตะทุกอุปกรณ์ออกจากระบบ โดยไม่เปลี่ยนรหัส |

## แก้ราคาสินค้า

ราคาอยู่ 2 ที่ และ **ฝั่ง Apps Script ถือเป็นราคาจริงที่ใช้คิดเงิน**

1. `apps-script/Code.gs` → ตัวแปร `PRODUCTS` (ต้อง Deploy ใหม่หลังแก้)
2. `js/products.js` → ใช้แสดงบนหน้าเว็บ

ถ้าสองที่ไม่ตรงกัน หน้าเว็บจะยึดราคาจาก Apps Script ให้อัตโนมัติ
และขึ้นคำเตือนใน Console ของเบราว์เซอร์ เพื่อไม่ให้คิดเงินผิด
แต่ควรแก้ให้ตรงกันทั้งสองที่อยู่ดี

## ข้อจำกัดและความเสี่ยงที่ควรรู้

**ลิงก์ Apps Script เป็นของสาธารณะ**
จำเป็นต้องเป็นแบบนั้น เพราะเบราว์เซอร์ลูกค้าต้องเรียกถึงได้ ผลที่ตามมา

- ใครที่รู้ลิงก์ **ส่งออเดอร์ปลอมเข้ามาได้** สคริปต์จำกัดไว้ 30 ออเดอร์ต่อ 10 นาที
  ถ้าถูกกวนหนัก ให้ Deploy ใหม่เพื่อเปลี่ยน URL แล้วอัปเดต `js/config.js`
- แต่ **อ่านข้อมูลออเดอร์และลูกค้าไม่ได้** ทุกคำสั่งที่อ่านข้อมูลต้องมีโทเคนจากการล็อกอิน

**การล็อกอินไม่แข็งเท่าระบบที่มีเซิร์ฟเวอร์เอง**

- โทเคนเก็บใน `sessionStorage` ไม่ใช่คุกกี้ `HttpOnly` เพราะ Apps Script อยู่ต่างโดเมน
  ตั้งคุกกี้ให้เว็บเราไม่ได้ ผลคือถ้ามีช่องโหว่ XSS โทเคนถูกขโมยได้
- รหัสผ่าน hash ด้วย PBKDF2-SHA256 5,000 รอบ (Apps Script ไม่มี scrypt/bcrypt ให้ใช้)
  แข็งน้อยกว่า scrypt จึงควรตั้งรหัสยาวหน่อย
- การจำกัดล็อกอินผิดนับรวมทั้งระบบ ไม่ได้แยกตาม IP เพราะ Apps Script ไม่บอก IP ผู้เรียก
  ผลข้างเคียง: ถ้ามีคนพยายามเดารหัสจนครบ 10 ครั้ง **คุณเองก็จะล็อกอินไม่ได้ 15 นาที**
  ถ้าเจอสถานการณ์นั้น ให้ไป Run ฟังก์ชัน `logoutAllDevices` หรือลบ property
  `loginFail` ในหน้า Apps Script (Project Settings → Script Properties)

**ข้อจำกัดของโควตา Google (บัญชีฟรี)**

- Apps Script รับได้ประมาณ 20,000 คำขอ/วัน และรวมเวลารัน 90 นาที/วัน
- เหลือเฟือสำหรับร้านขนม แต่ถ้ายอดโตมากควรย้ายไประบบที่มีเซิร์ฟเวอร์จริง

**ไม่มีการชำระเงินอัตโนมัติ** — ลูกค้าโอนพร้อมเพย์แล้วส่งสลิปมาทางแชต คุณกดเปลี่ยนสถานะเอง
